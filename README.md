# Trade Card App

App mobile para colecionar e trocar cards colecionáveis (trading cards).

## Funcionalidades planejadas

- Cadastro e login de usuários
- Coleção pessoal: adicionar, organizar e visualizar cards
- Lista de desejos (cards que o usuário procura)
- Propostas de troca entre usuários
- Chat para negociar as trocas
- Busca e filtros por coleção, raridade e condição

## Stack sugerida

- React Native com Expo
- TypeScript
